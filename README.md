# HR Analytics Dashboard (Power BI)

Interactive Power BI dashboard to analyze employee attrition, workforce demographics and job satisfaction.

## Key Metrics
- Total Employees: 1,470
- Attrition Count: 237
- Attrition Rate: 16.12%
- Active Employees: 1,233
- Average Age: 37

## Dashboard Includes
- Attrition by department, age group, gender and education
- Job satisfaction vs. job role matrix
- KPI cards and a department slicer

## Tools Used
Power BI (Data Modeling, DAX, Custom Visualizations), Power Query (data cleaning and transformation)
